# AxTrade Config - Español

Configuración personalizada en español para **AxTrade**, diseñada para ofrecer un sistema de intercambios más claro, organizado y visual para servidores de Minecraft.

La configuración modifica tanto la **interfaz de Trade** como los diferentes mensajes mostrados en el chat, incorporando un diseño uniforme para objetos, dinero, experiencia, confirmaciones y estados del intercambio.

El objetivo es proporcionar una experiencia sencilla para los jugadores, permitiendo identificar rápidamente qué están ofreciendo, cuándo una oferta está confirmada y el estado actual del otro jugador.

---

Vista del sistema de **ayuda administrativa de AxTrade**, donde se muestran los comandos principales disponibles para administrar y utilizar los intercambios.

Desde este apartado pueden consultarse comandos para enviar, aceptar o rechazar solicitudes, activar o desactivar intercambios, recargar el plugin, forzar un Trade entre jugadores y visualizar previamente la interfaz.

## Activar y desactivar solicitudes de intercambio

![Solicitudes de intercambio](Capturas/Captura%20de%20pantalla%202026-09-28%20085202.png)

Ejemplo del sistema utilizado para **activar o desactivar las solicitudes de Trade**.

El jugador puede decidir si desea recibir invitaciones de intercambio de otros usuarios. El chat informa claramente cuando las solicitudes quedan bloqueadas y cuando vuelven a habilitarse.

## Interfaz principal de Trade

![Interfaz principal](Capturas/Captura%20de%20pantalla%202026-09-28%20085220.png)

Vista general de la **interfaz principal de intercambio** configurada para AxTrade.

El menú divide claramente las zonas correspondientes a cada jugador y proporciona diferentes controles para administrar la oferta antes de completar el intercambio.

Desde esta interfaz pueden añadirse objetos y utilizar las opciones configuradas para dinero, experiencia y confirmación.

---

## Sistema de confirmación

![Confirmar Trade](Capturas/Captura%20de%20pantalla%202026-09-28%20085230.png)

Botón de **confirmación de oferta** utilizado cuando el jugador considera que todos los elementos introducidos en el Trade son correctos.

El lore informa de forma clara sobre la función del botón y permite confirmar la oferta antes de realizar definitivamente el intercambio.

---

## Cancelación de confirmación

![Cancelar confirmación](Capturas/Captura%20de%20pantalla%202026-09-28%20085236.png)

Una vez confirmada la oferta, el botón cambia visualmente para indicar que el jugador ya se encuentra preparado.

Si necesita modificar algún objeto o cambiar parte de su oferta, puede **cancelar la confirmación** y continuar editando el intercambio antes de finalizarlo.

---

## Oferta de dinero

![Oferta de dinero](Capturas/Captura%20de%20pantalla%202026-09-28%20085243.png)

Sistema destinado a incluir **dinero dentro del intercambio**.

La interfaz muestra claramente la cantidad económica que está ofreciendo el jugador y proporciona una opción directa para modificar dicho valor antes de confirmar el Trade.

Esto permite realizar intercambios combinando objetos y dinero dentro de una misma operación.

---

## Oferta de experiencia

![Oferta de experiencia](Capturas/Captura%20de%20pantalla%202026-09-28%20085245.png)

Opción diseñada para incluir **experiencia (EXP)** como parte de la oferta.

El jugador puede visualizar la cantidad de experiencia introducida y modificarla directamente desde la interfaz, permitiendo utilizarla junto con objetos y otros elementos disponibles durante el intercambio.

---

## Estado del otro jugador

![Estado esperando](Capturas/Captura%20de%20pantalla%202026-09-28%20085251.png)

Indicador visual encargado de mostrar el **estado de confirmación del otro jugador**.

Mientras la otra persona todavía no haya confirmado su oferta, aparecerá el estado **Esperando...**, indicando que el intercambio aún no puede finalizar.

Este sistema ayuda a identificar rápidamente cuál de los jugadores todavía debe revisar y confirmar su parte del Trade.

## Características principales

- Interfaz de Trade completamente personalizada.
- Textos y mensajes adaptados al español.
- Diseño de lore limpio y organizado.
- Espacios independientes para los objetos de cada jugador.
- Sistema visual de confirmación de ofertas.
- Posibilidad de cancelar una confirmación antes de finalizar.
- Oferta de dinero directamente desde la GUI.
- Oferta de experiencia dentro del intercambio.
- Indicador del estado de confirmación del otro jugador.
- Sistema para activar o desactivar solicitudes de Trade.
- Mensajes administrativos personalizados.
- Confirmación visual al recargar la configuración.
- Ayuda integrada para comandos de jugadores y administradores.
- Diseño pensado para mantener una interfaz sencilla y fácil de comprender.

## Archivos de la configuración

La configuración incluye los diferentes archivos utilizados por **AxTrade** para controlar tanto su funcionamiento como la apariencia del sistema de intercambios.

Entre ellos se encuentran:

- `config.yml`
- `guis.yml`
- `lang.yml`
- `currencies.yml`
- `toggled.yml`
- Archivos adicionales utilizados por el plugin.

---

## Instalación

1. Instala **AxTrade** en tu servidor.
2. Inicia el servidor una vez para generar sus archivos.
3. Detén el servidor.
4. Sustituye los archivos correspondientes por los incluidos en esta configuración.
5. Inicia nuevamente el servidor.
6. Comprueba la interfaz y los mensajes dentro del juego.

---

## Dependencia

Esta configuración **no incluye el plugin AxTrade**.

Para utilizarla necesitas tener instalado previamente **AxTrade**.
